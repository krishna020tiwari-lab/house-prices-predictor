# house-prices-predictor
End-to-end Machine Learning pipeline predicting house prices using key features like square footage, bedrooms, and property age. Built with Python and Scikit-Learn, it covers data generation, linear regression modeling, metric evaluation, and model serialization via Joblib, deployed through an interactive Streamlit web app.
# 🏠 House Price Predictor (Linear Regression & Streamlit)

An end-to-end Machine Learning project that predicts home values based on property features (Square Footage, Bedrooms, and Age) using Multiple Linear Regression.

## 🚀 Features
- **Model Training:** Multiple Linear Regression trained using Scikit-Learn.
- **Model Persistence:** Model serialized and saved using `joblib`.
- **Interactive UI:** Web application built with Streamlit for real-time price estimation.
